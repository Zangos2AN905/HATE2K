# HATE2K
This is a corruptor for RPG Maker 2k(3) games.

## Features

- Shuffle dialogue engines: 
    - Shuffle dialogue from other maps and the current map
    - Shuffle words and nouns
    - Shuffle letter case
    - Create nonsense (that sounds like actual in-game dialogue) using Markov Chain and other methods

- Shuffle map transfers
- Shuffle certain events
- Shuffle assets
- Randomize stats
- Shuffle player characters
- Corrupt MIDI files (while being playable)
- Corrupt WAV/MP3 files (requires FFmpeg, inserts random noise and others) 
- Game merger
- more to come...
